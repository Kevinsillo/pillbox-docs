Pillbox runs as a single binary on Linux, macOS, and Windows. The installer sets up the binary, MCP server, and agent skill in one step. The skill installs to whichever AI provider you have configured — Claude Code or OpenCode.

## One-line install

<Tabs syncKey="os">
  <TabItem label="Linux / macOS">
    ```bash
    curl -fsSL https://get.pillbox.dev | bash
    ```

    The installer:

    1. Detects your platform (Linux/macOS, x86_64/aarch64)
    2. Downloads the `pillbox` binary from GitHub Releases
    3. Installs it to `~/.local/bin` (Linux) or `/usr/local/bin` (macOS)
    4. Installs the MCP server to `~/.pillbox/mcp/`
    5. Installs the agent skill to your provider's config folder (`~/.claude/skills/pillbox/` for Claude Code, `~/.config/opencode/skill/pillbox/` for OpenCode)
    6. Creates the global database at `~/.pillbox/pillbox.db`
  </TabItem>
  <TabItem label="Windows">
    Run in PowerShell:

    ```powershell
    irm https://get.pillbox.dev/install.ps1 | iex
    ```

    The installer:

    1. Detects your architecture (x86_64/aarch64)
    2. Downloads the `pillbox` binary from GitHub Releases
    3. Installs it to `%LOCALAPPDATA%\Programs\pillbox`
    4. Adds the install directory to your user `PATH` (no Administrator needed)
    5. Creates the global database at `~/.pillbox/pillbox.db`

    You may need to open a new terminal for the updated `PATH` to take effect.

    <Aside type="caution">
      The installer itself runs without elevation, but `pillbox serve install` and `pillbox serve uninstall` require an elevated (Administrator) PowerShell. They register a Windows service and edit the hosts file.
    </Aside>
  </TabItem>
</Tabs>

### Options

<Tabs syncKey="os">
  <TabItem label="Linux / macOS">
    Install a specific version:

    ```bash
    curl -fsSL https://get.pillbox.dev | bash -s -- --version 0.4.0
    ```

    Custom install directory:

    ```bash
    curl -fsSL https://get.pillbox.dev | bash -s -- --install-dir /usr/local/bin
    ```
  </TabItem>
  <TabItem label="Windows">
    Install a specific version or use a custom directory with environment variables:

    ```powershell
    $env:PILLBOX_VERSION = '0.4.0'
    $env:PILLBOX_INSTALL_DIR = 'C:\Tools\pillbox'
    irm https://get.pillbox.dev/install.ps1 | iex
    ```
  </TabItem>
</Tabs>

## Manual installation

Download the binary for your platform from [GitHub Releases](https://github.com/Kevinsillo/pillbox/releases):

| Platform | Binary |
|---|---|
| Linux x86_64 | `pillbox-linux-x86_64` |
| Linux aarch64 | `pillbox-linux-aarch64` |
| macOS arm64 | `pillbox-darwin-aarch64` |
| macOS x86_64 | `pillbox-darwin-x86_64` |
| Windows x86_64 | `pillbox-windows-x86_64.exe` |
| Windows aarch64 | `pillbox-windows-aarch64.exe` |

Then follow these steps:

<Steps>

1. Place it on your `$PATH` and make it executable:

   ```bash
   chmod +x pillbox
   mv pillbox ~/.local/bin/
   ```

2. Install the MCP server:

   ```bash
   pillbox mcp install
   ```

   Requires Node.js ≥ 18.

3. Install the Pillbox skill:

   ```bash
   pillbox skill install
   ```

   Installs the Pillbox skill to the global configuration folder of your AI provider (e.g. `~/.claude/skills/pillbox/` for Claude Code).

4. (Optional) Install SDD skill and agents:

   ```bash
   ./skills/install.sh
   ```

   Installs the Spec-Driven Development skill, sub-agents, and commands to the global configuration folder of each detected provider (Claude Code, OpenCode). The script detects which providers are installed and lets you choose.

</Steps>

## Verify the installation

```bash
pillbox status
```

Shows binary path, global database, MCP server, and skill status.

## Building from source

Requires Rust 1.75+ and Node.js 20+.

```bash
git clone https://github.com/Kevinsillo/pillbox
cd pillbox
make build-full
./core/target/release/pillbox mcp install
./core/target/release/pillbox skill install
```
