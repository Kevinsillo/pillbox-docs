Pillbox runs as a single binary on Linux, macOS, and Windows. The one-line installer places the binary on your `PATH`. Then two more commands set up the MCP server and the agent skill.

## One-line install

<Tabs syncKey="os">
  <TabItem label="Linux / macOS">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/Kevinsillo/pillbox/main/install.sh | bash
    ```

    The installer:

    1. Detects your platform (Linux/macOS, x86_64/aarch64)
    2. Downloads the `pillbox` binary from GitHub Releases
    3. Installs it to `~/.local/bin` (Linux) or `/usr/local/bin` (macOS)
  </TabItem>
  <TabItem label="Windows">
    Run in PowerShell:

    ```powershell
    irm https://raw.githubusercontent.com/Kevinsillo/pillbox/main/install.ps1 | iex
    ```

    The installer:

    1. Detects your architecture (x86_64/aarch64)
    2. Downloads the `pillbox` binary from GitHub Releases
    3. Installs it to `%LOCALAPPDATA%\Programs\pillbox`
    4. Adds the install directory to your user `PATH` (no Administrator needed)

    You may need to open a new terminal for the updated `PATH` to take effect.

    <Aside type="caution">
      The installer itself runs without elevation, but `pillbox serve install` and `pillbox serve uninstall` require an elevated (Administrator) PowerShell. They register a Windows service and edit the hosts file.
    </Aside>
  </TabItem>
</Tabs>

### Options

<Tabs syncKey="os">
  <TabItem label="Linux / macOS">
    Install a specific version:

    ```bash
    curl -fsSL https://raw.githubusercontent.com/Kevinsillo/pillbox/main/install.sh | bash -s -- --version 0.15.3
    ```

    Custom install directory:

    ```bash
    curl -fsSL https://raw.githubusercontent.com/Kevinsillo/pillbox/main/install.sh | bash -s -- --install-dir /usr/local/bin
    ```
  </TabItem>
  <TabItem label="Windows">
    Install a specific version or use a custom directory with environment variables:

    ```powershell
    $env:PILLBOX_VERSION = '0.15.3'
    $env:PILLBOX_INSTALL_DIR = 'C:\Tools\pillbox'
    irm https://raw.githubusercontent.com/Kevinsillo/pillbox/main/install.ps1 | iex
    ```
  </TabItem>
</Tabs>

## Manual installation

Download the binary for your platform from [GitHub Releases](https://github.com/Kevinsillo/pillbox/releases):

| Platform | Binary |
|---|---|
| Linux x86_64 | `pillbox-linux-x86_64` |
| Linux aarch64 | `pillbox-linux-aarch64` |
| macOS arm64 | `pillbox-darwin-aarch64` |
| macOS x86_64 | `pillbox-darwin-x86_64` |
| Windows x86_64 | `pillbox-windows-x86_64.exe` |
| Windows aarch64 | `pillbox-windows-aarch64.exe` |

Then follow these steps:

<Steps>

1. Place the binary on your `PATH`.

   Linux / macOS:

   ```bash
   chmod +x pillbox
   mv pillbox ~/.local/bin/
   ```

   Windows — move the `.exe` into a folder on your `PATH`:

   ```powershell
   New-Item -ItemType Directory -Force "$env:LOCALAPPDATA\Programs\pillbox" | Out-Null
   Move-Item .\pillbox-windows-x86_64.exe "$env:LOCALAPPDATA\Programs\pillbox\pillbox.exe"
   ```

2. Install the MCP server:

   ```bash
   pillbox mcp install
   ```

   Requires Node.js ≥ 18. Downloads the server bundle and registers it with your AI provider.

3. Install the Pillbox skill:

   ```bash
   pillbox skill install
   ```

   Installs the Pillbox skill to your provider's global config folder (`~/.claude/skills/pillbox/` for Claude Code, `~/.config/opencode/skill/pillbox/` for OpenCode).

4. (Optional) Install the SDD skill, agents, and commands.

   Linux / macOS:

   ```bash
   ./skills/install.sh
   ```

   Windows:

   ```powershell
   .\skills\install.ps1
   ```

   Installs the Spec-Driven Development skill, sub-agents, and commands to each detected provider (Claude Code, OpenCode). The script detects which providers are installed and lets you choose.

</Steps>

## Verify the installation

```bash
pillbox status
```

Shows binary path, global database, MCP server, and skill status.

## Building from source

Each component lives in its own repository. Build any of them directly from source.

### Binary

Requires Rust 1.75+ and Node.js 20+ — the web UI is embedded at build time.

```bash
git clone https://github.com/Kevinsillo/pillbox
cd pillbox
make build-full
./core/target/release/pillbox mcp install
./core/target/release/pillbox skill install
```

On Windows, build the web UI with `pnpm build` in `webui/`, then run `cargo build --release` in `core/`.

### MCP server

Builds the Node bundle and installs it to `~/.pillbox/mcp/`. Requires Node.js ≥ 18 and pnpm, bun, or npm.

<Tabs syncKey="os">
  <TabItem label="Linux / macOS">
    ```bash
    git clone https://github.com/Kevinsillo/pillbox-mcp
    cd pillbox-mcp
    ./install.sh
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    git clone https://github.com/Kevinsillo/pillbox-mcp
    cd pillbox-mcp
    .\install.ps1
    ```
  </TabItem>
</Tabs>

Then run `pillbox mcp install` to register it with your AI providers.
