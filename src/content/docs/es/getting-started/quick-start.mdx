Esta página te lleva de una instalación nueva a una configuración de Pillbox funcionando — binario instalado, MCP conectado y tu primer bottle registrado.

## Prerequisitos

- Binario `pillbox` instalado ([guía de instalación](/es/getting-started/installation/))
- Claude Code u otro asistente IA compatible con MCP

## Configuración

<Steps>
1. Inicializa un bottle en el directorio de tu proyecto

   ```bash
   cd tu-proyecto
   pillbox bottle init
   ```

   El asistente pregunta por un nombre para mostrar y el alcance (`local` o `global`). Elige `global` si quieres que el conocimiento de este proyecto sea accesible desde cualquier lugar.

2. Instala el servidor MCP

   ```bash
   pillbox mcp install
   ```

   Instala el servidor MCP de Node.js en `~/.pillbox/mcp/` y lo registra con tu agente de IA. El comando pregunta qué proveedor configurar (Claude Code u OpenCode) — o pasa `--provider claude|opencode`.

3. Instala la skill del agente

   ```bash
   pillbox skill install
   ```

   Instala la skill de Pillbox en la carpeta de configuración global de tu proveedor de IA (`~/.claude/skills/pillbox/` para Claude Code, `~/.config/opencode/skill/pillbox/` para OpenCode), que guía al agente para usar las herramientas de Pillbox correctamente. Con más de un proveedor instalado, el comando pregunta a cuál apuntar — o pasa `--provider claude|opencode`.

4. Reinicia tu agente de IA (Claude Code u OpenCode)

   Ejecuta `/mcp` para confirmar que `pillbox` está conectado y sus herramientas aparecen en la lista.

5. Verifica que todo funciona

   ```bash
   pillbox status
   ```

   Deberías ver el binario, la DB global, el servidor MCP y la skill reportados como activos.
</Steps>

## Tu primera sesión

Una vez completada la configuración, Claude usa Pillbox automáticamente. Al inicio de una nueva sesión recupera el contexto reciente vía `bottle_context` y `prescription_context`. Mientras trabaja, guarda pills con las decisiones y descubrimientos. Al final, guarda un resumen de sesión.

No necesitas hacer nada — la skill gestiona el flujo de trabajo.

## Revisa lo que guardó tu agente

Inicia la interfaz web para explorar pills, cápsulas y prescriptions:

```bash
pillbox serve start
```

Luego abre `http://localhost:4242` en tu navegador.

La UI es una capa de supervisión — úsala para detectar entradas redundantes, incorrectas o mal redactadas y corregirlas. El agente gestiona todas las escrituras durante el trabajo normal.
