Pillbox corre como un binario único en Linux, macOS y Windows. El instalador configura el binario, el servidor MCP y la skill de Claude Code en un solo paso.

## Instalación en una línea

<Tabs syncKey="os">
  <TabItem label="Linux / macOS">
    ```bash
    curl -fsSL https://get.pillbox.dev | bash
    ```

    El instalador:

    1. Detecta tu plataforma (Linux/macOS, x86_64/aarch64)
    2. Descarga el binario `pillbox` desde GitHub Releases
    3. Lo instala en `~/.local/bin` (Linux) o `/usr/local/bin` (macOS)
    4. Instala el servidor MCP en `~/.pillbox/mcp/`
    5. Instala la skill de Claude Code en `~/.claude/skills/pillbox/`
    6. Crea la base de datos global en `~/.pillbox/pillbox.db`
  </TabItem>
  <TabItem label="Windows">
    Ejecuta en PowerShell:

    ```powershell
    irm https://get.pillbox.dev/install.ps1 | iex
    ```

    El instalador:

    1. Detecta tu arquitectura (x86_64/aarch64)
    2. Descarga el binario `pillbox` desde GitHub Releases
    3. Lo instala en `%LOCALAPPDATA%\Programs\pillbox`
    4. Añade el directorio de instalación a tu `PATH` de usuario (sin permisos de administrador)
    5. Crea la base de datos global en `~/.pillbox/pillbox.db`

    Puede que necesites abrir una nueva terminal para que el `PATH` actualizado tenga efecto.

    <Aside type="caution">
      El instalador se ejecuta sin elevación, pero `pillbox serve install` y `pillbox serve uninstall` requieren una PowerShell elevada (Administrador). Registran un servicio de Windows y editan el archivo hosts.
    </Aside>
  </TabItem>
</Tabs>

### Opciones

<Tabs syncKey="os">
  <TabItem label="Linux / macOS">
    Instalar una versión específica:

    ```bash
    curl -fsSL https://get.pillbox.dev | bash -s -- --version 0.4.0
    ```

    Directorio de instalación personalizado:

    ```bash
    curl -fsSL https://get.pillbox.dev | bash -s -- --install-dir /usr/local/bin
    ```
  </TabItem>
  <TabItem label="Windows">
    Instala una versión específica o usa un directorio personalizado con variables de entorno:

    ```powershell
    $env:PILLBOX_VERSION = '0.4.0'
    $env:PILLBOX_INSTALL_DIR = 'C:\Tools\pillbox'
    irm https://get.pillbox.dev/install.ps1 | iex
    ```
  </TabItem>
</Tabs>

## Instalación manual

Descarga el binario para tu plataforma desde [GitHub Releases](https://github.com/Kevinsillo/pillbox/releases):

| Plataforma | Binario |
|---|---|
| Linux x86_64 | `pillbox-linux-x86_64` |
| Linux aarch64 | `pillbox-linux-aarch64` |
| macOS arm64 | `pillbox-darwin-aarch64` |
| macOS x86_64 | `pillbox-darwin-x86_64` |
| Windows x86_64 | `pillbox-windows-x86_64.exe` |
| Windows aarch64 | `pillbox-windows-aarch64.exe` |

Luego sigue estos pasos:

<Steps>

1. Colócalo en tu `$PATH` y hazlo ejecutable:

   ```bash
   chmod +x pillbox
   mv pillbox ~/.local/bin/
   ```

2. Instala el servidor MCP:

   ```bash
   pillbox mcp install
   ```

   Requiere Node.js ≥ 18.

3. Instala la skill de Pillbox:

   ```bash
   pillbox skill install
   ```

   Instala la skill de Pillbox en la carpeta de configuración global de tu proveedor agentico (p. ej. `~/.claude/skills/pillbox/` para Claude Code).

4. (Opcional) Instala la skill y agentes SDD:

   ```bash
   ./skills/install.sh
   ```

   Instala la skill de Spec-Driven Development, los sub-agentes y los commands en la carpeta de configuración global de cada proveedor detectado (Claude Code, OpenCode). El script detecta los providers instalados y te permite elegir.

</Steps>

## Verificar la instalación

```bash
pillbox status
```

Muestra la ruta del binario, base de datos global, servidor MCP y estado de la skill.

## Compilar desde el código fuente

Requiere Rust 1.75+ y Node.js 20+.

```bash
git clone https://github.com/Kevinsillo/pillbox
cd pillbox
make build-full
./core/target/release/pillbox mcp install
./core/target/release/pillbox skill install
```
