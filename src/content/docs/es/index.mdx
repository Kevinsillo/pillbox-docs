## Cómo funciona

Pillbox organiza el conocimiento en cuatro capas:

- **Bottles** — uno por proyecto. Mapea un directorio a una base de datos.
- **Prescriptions** — sesiones de trabajo dentro de un bottle. Una abierta a la vez.
- **Pills** — conocimiento específico del proyecto guardado durante una sesión. Buscable.
- **Capsules** — conocimiento personal, entre proyectos. Convenciones, preferencias, contexto.

Tu agente abre una prescription al comenzar, guarda pills con las decisiones y los bugs que resuelve, y cierra la prescription con un resumen al terminar. En la siguiente sesión, llama a `pill_context` para restaurar todo.
