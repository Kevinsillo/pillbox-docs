Pillbox expone sus herramientas a los agentes IA mediante el [Model Context Protocol](https://modelcontextprotocol.io). El servidor MCP es un proceso Node.js que se comunica con el binario `pillbox` mediante stdin/stdout.

## Cómo funciona

El servidor MCP no accede directamente a la base de datos. Se comunica con el binario `pillbox` mediante `pillbox mcp run`:

1. El servidor MCP recibe una llamada de herramienta del agente.
2. Lanza `pillbox mcp run` como subproceso.
3. Escribe un payload JSON en stdin: `{ "tool": "pill_take", "input": { ... } }`.
4. Lee la respuesta JSON de stdout.
5. Devuelve la respuesta al agente.

El servidor MCP no tiene estado. Toda la persistencia la gestiona el core de Rust.
